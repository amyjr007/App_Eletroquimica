# Eletroquímica — Audiobook Interativo

Aplicativo educacional interativo sobre **Eletroquímica**, com narração em áudio,
animações e um laboratório de Oxi-Redução manipulável.

## Módulos

1. **Introdução / Oxi-Redução** — definição animada e laboratório interativo (arraste as lâminas de Zn e Cu).
2. **Pilhas**
3. **Eletrólise** — célula eletrolítica animada.

## Como usar

Abra o arquivo [`index.html`](index.html) em um navegador moderno. Não requer instalação
nem servidor — é uma página única (HTML + CSS + JavaScript) com os áudios na pasta [`audio/`](audio/).
